# Опциональное файловое хранение

Без `DEMEU_DATA_DIR` используется прежний memory store. С заданным каталогом сессии и токены сохраняются в `sessions.json`; направления используют отдельный snapshot и не входят в TTL сессий. Локально допустим `DEMEU_DATA_DIR=data/runtime`. Каталог runtime исключён из git и Docker build context.

Поддерживается один Node-процесс на локальном диске. Несколько контейнеров/writers, Node cluster, NFS и одновременный blue/green с общим volume не поддерживаются. Реестр путей защищает от второго adapter в том же процессе; это не межпроцессная блокировка. Обычный рестарт после остановки старого процесса не требует удаления lock-файла.

Запись последовательно создаёт отдельный кандидат, проверяет JSON, записывает временный файл с правами 0600, выполняет fsync файла, rename и fsync каталога. Успешный ответ возвращается после фиксации. Ошибка после rename закрывает экземпляр для дальнейшей работы до повторного открытия: нельзя затереть возможную committed запись старым RAM-состоянием. Повреждённый snapshot, неизвестная версия или файл больше 32 MiB приводят к ошибке, а не к пустому хранилищу. Увеличение лимита требует оценки объёма и времени записи; старые направления не удаляются ради освобождения места.

При первом создании каталога применяются права 0700. Существующий каталог должен быть заранее защищён оператором. После аварийной остановки могут остаться приватные временные файлы; они не используются как committed snapshot. Их разбор/удаление — отдельная операция обслуживания на остановленном экземпляре.

## Доставка и TTL

Сессии сохраняют 60 минут collecting, 24 часа terminal и 7 суток жизни токена по июльскому контракту. Нулевой опрос удаляется без уведомления. Aborted фиксируется до вызова notifier, отправка выполняется вне транзакции. Pending/failed остаются видимыми после рестарта и автоматически не переотправляются. Рестарт между успешной внешней отправкой и локальным подтверждением неоднозначен; exactly-once не заявляется.

Долговременная история направления не является копией полного транскрипта и не очищается по этим TTL. Сроки хранения направлений, политика доступа и условия персонального пилота требуют отдельного решения до production-включения. Эта опция не является разрешением на бессрочный медицинский архив.

## Подготовка Docker

Опциональный `deploy/compose.storage.yml` подключается последним overlay после выбора proxy. `DEMEU_HOST_DATA_DIR` должен указывать на уже существующий абсолютный каталог на сервере, принадлежащий UID/GID 1001:1001, с правами 0700. Overlay не создаёт отсутствующий host-каталог и не меняет права самостоятельно. В контейнере каталог доступен как `/var/lib/demeu`.

Не запускать два приложения с этим каталогом. Deploy/rollback сохраняют каталог; откат приложения на неподдерживаемую schema version должен завершаться ошибкой открытия. Backup берётся после остановки единственного writer, включает committed snapshots сессий, направлений и журнала доставки (если создан), а также отдельно защищённую конфигурацию учётных записей; подробности в `workspace-deploy.md`. Копии хранятся с теми же ограничениями доступа. Restore проверяется на отдельном локальном каталоге до подключения к приложению. Не использовать `docker compose down -v` как шаг обновления. На VPS в этой итерации ничего не запускалось.
