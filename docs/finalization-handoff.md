## Сообщение Ардану

Ардан, реализованы пациентский пакет по персональной ссылке, самостоятельный
PDF RU/KK, отметки пациента и отдельное подтверждение врача; исправление
врачебного заключения с историей; ведомственная аналитика на реальных агрегатах
Case 1; исследовательский B3 по точному регистрационному снимку; МИС pull/ACK и
OpenAPI. Убраны токены из Telegram, исправлена публикация приватных агрегатов,
актуализирован provenance eval и проверка совместимости восстановления.

Сквозная проверка проходит на изолированных вымышленных данных, без запросов
в Anthropic: RU/KK опрос, emergency, пакет, две отметки, подтверждение врача,
два PDF, B3, МИС ACK, перезапуск без повторной отправки, сохранность исходной
пациентской ссылки после очистки чата. Независимое ревью не нашло оставшихся
P0/P1/P2. В браузере отдельно проверены роли, desktop/mobile, состояния ошибок
и локализованный текст PDF.

Это локальная готовность к проверке релиза. Production-приёмка новой версии
ещё не выполнена. Клинический справочник остаётся `validated:false`, B3 —
исследование; реальная МИС не подключена.
