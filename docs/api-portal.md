# Demeu API portal

Интерактивный справочник доступен по `/api-docs`. Это first-party интерфейс внутри Next.js-приложения, без Swagger UI и отдельного генератора схем.

## Источник контракта

`lib/api-catalog.ts` — единый типизированный каталог для навигации, карточек операций, примеров и сквозных историй. Для каждой операции он хранит:

- HTTP-метод и путь;
- модель доступа и границу роли;
- поля запроса;
- успешный ответ;
- коды ошибок;
- безопасные примеры cURL и Fetch.

Примеры используют только вымышленные идентификаторы, псевдонимы и placeholders. Cookies, пароли, Telegram chat id и API-ключи в каталог не включаются.
Base URL берётся из `APP_BASE_URL` при каждом серверном рендере страницы. cURL-вход сохраняет
HttpOnly workspace-cookie в локальный cookie jar, а старт опроса — capability-cookie пациента в
отдельный jar; следующие примеры используют эти файлы. Для `/api/link` показана отдельная замена
заголовка только для legacy-режима без рабочего пространства.

## Защита от рассинхронизации

`tests/unit/api-docs.test.tsx` рекурсивно читает `app/api/**/route.ts`, извлекает экспортированные HTTP-методы и сравнивает их с каталогом как два точных множества. Новый route handler без карточки или устаревшая карточка без route handler делают тест красным.

Тот же тест проверяет обязательные секции контракта, точные error sets критического chat-флоу, query-контракт списка направлений, оба языка примеров, endpoint anchors, навигацию, три сквозные истории и отсутствие generic Swagger-зависимостей.

## UX

- desktop: фиксированная поисковая навигация, двухколоночная карточка «контракт + примеры»;
- mobile: горизонтальная навигация, одноколоночный контракт, крупные controls и уникальное доступное имя каждой сокращённой ссылки;
- keyboard: skip-link, семантические landmarks, видимый search focus и вкладки с roving `tabIndex`, `aria-controls`, Arrow Left/Right, Home и End;
- reduced motion: анимации и переходы отключаются по системной настройке;
- копирование: каждый запрос и ответ копируется отдельно.

Портал документирует API, но не выполняет запросы сам. Это исключает случайный живой вызов аналитического контура из страницы документации.
