## Правила готовности

Справочник остаётся `validated:false` до врачебного подтверждения. Пациент видит это ограничение; наличие самоотметок не включает подтверждённую готовность.

B3 остаётся исследовательской оценкой с ограничениями лицензии, временной доступности признаков и переносимости. Никакие отсутствующие данные не подставляются как реальные.

Проверка живой МИС, клиническая валидация и точный SHA production — отдельные факты. Их нельзя заменить локальными тестами или отметить выполненными без доказательств.

В этом проходе используются локальные моки внешних API. Значения ключей и реальные данные пациентов не входят в артефакты проверки.

На `a8e264c`: 1444 passed / 10 failed / 4 skipped. Два падения parity вызваны отсутствием локального raw split и feature spec; после подключения существующих игнорируемых файлов parity 153/153. Оставшиеся восемь падений — перенос технического README и формулировка в новом продуктовом README. Они включены в этап 6; проверки публикации метрик сохраняются.

## Ход работ

Этап 1 реализован и проверен локально: 28 новых тестов, 102 теста затронутого среза, lint/tsc, независимое ревью; в браузере две отметки, подтверждение врачом, PDF, RU/KK на мобильном и проверки доступа. В production эти изменения ещё не проверены.

Консервативный пакет этапа 3 сверяется с [приложением 5 действующего Стандарта](https://old.adilet.zan.kz/rus/docs/V2200027218): условные позиции и отсутствие обязательной консультации терапевта отражаются отдельным черновым перечнем. Это сверка источника, клиническая валидация остаётся отдельной приёмкой.

Этап 2 реализован и проверен локально: 21 тест Case1, lint/tsc, независимое ревью и браузер (owner/analyst, фильтры, empty, desktop/mobile). API возвращает реальный агрегат; доктору endpoint недоступен403. Регистрация новых API в портале выполняется этапом 5.

Этап 3 реализован и проверен локально: 148 тестов затронутого среза, lint/tsc, независимое повторное ревью. В браузере сохранение заключения и его причины, переходы контекста, история, две отметки и одно подтверждение, RU/KK PDF, пустая памятка при неизвестном контексте, запрет owner на изменение заключения. Схема v4 мигрирует прежние отчёты как исторические; справочник остаётся validated:false.

Этап 4 реализован и проверен локально: B3 JSON-артефакт, неизменяемые семь регистрационных входов, схема v5, негативные проверки HTTP 11/11, Python 56/56 без пропусков, lint/tsc и независимое ревью. Реальный TS совпал с Python на 223 353 мартовских записях (ноль расхождений по порогу). Браузер: ручной ввод, исследовательская оценка и покрытие каждого поля, мобильный экран 390px без переполнения, роли и некорректный query. Лицензия данных и переносимость на пилот не проверены.

Этап 5 реализован и проверен локально: МИС pull/ACK, отдельные ключи и права организации, атомарный outbox, схема v6, повторная доставка и отзыв статусов. OpenAPI 3.1 и портал описывают 38 успешных и 4 отрицательных операции. Тесты этапа 44/44, затронутый срез 89/89, lint/tsc, независимое ревью МИС и OpenAPI. Реальные DTO проверены JSON Schema валидатором. Браузер: портал и OpenAPI 200, desktop/mobile без переполнения. Реальные ключи МИС, согласование идентификаторов/повторов/SLA и врачебная валидация остаются внешней приёмкой.

Этап 6 реализован и проверен локально: 222 профильных Vitest, четыре Python-теста с негативными контролями, corpus/report/candidate/runtime verifiers, Ruff, lint/tsc и два независимых ревью. Telegram без токенов, стабильные приватные агрегаты, адресная очистка schema6 и строгая совместимость образа восстановления. МИС получает опциональный приватный read-only mount через штатные скрипты. Образ без встроенного reader marker при существующем состоянии блокирует первый переход; требуется проверяемая подготовка восстановления и writable backup. Выкладка не выполнялась.

Этап 7 реализован и проверен локально: точный сквозной срез 64/64, независимое ревью без оставшихся P0/P1/P2; parent повторил все семь этапов. Все 29 gates зелёные, полный Vitest/lint/TypeScript/build прошли. Свежий браузерный RU/KK пациентский пакет, две отметки/одно подтверждение и PDF проверены. Финальное обновление ClickUp отклонено из-за дневного лимита MCP100/100; [передача Ардану](finalization-handoff.md) подготовлена локально. Новый релиз не опубликован.
