## 2. Твоя основная часть — ML-слой

Сейчас аналитика работает на LLM (claude-sonnet-5) + rule-based флагах, чтобы демо было живым уже сейчас. **Шов — `lib/triage.ts`, функция `analyze(messages)`.** Она принимает транскрипт диалога и возвращает `TriageResult` (тип в `lib/types.ts`):

- `anamnesis` — извлечение сущностей;
- `urgency` + `urgency_reasons` — скоринг срочности;
- `routing[]` — классификатор специальности (top-N с вероятностями);
- `hypothesis` — предварительная гипотеза;
- `red_flags` — rule-based, в `lib/redflags.ts` (объяснимость; **оставляем rule-based**).

**Задача:** подменить внутренности `analyze()` на обученные модели (скоринг/маршрутизация) на **DDXPlus + открытых symptom-датасетах**, сохранив сигнатуру и формат `TriageResult`. Фронт и API трогать не нужно — они уже готовы под этот контракт.

Данные и методология (источник/структура/ограничения/признаки) — описать для README и деки (это критерий оценки, 15 баллов).
