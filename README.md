# Demeu · команда Specimen AI · GovTech Camp 2026

Кейс 1 «Нагрузка на стационары и очереди на плановую госпитализацию».
Команда: Ардан (продукт, данные, ML-аналитика) и Алмаз Есеньязов (разработка, инфраструктура).

## Коротко

Demeu показывает ведомству и руководителю, где в системе плановой госпитализации копятся отказы и ожидание, и прогнозирует поступления в каждый стационар на месяц вперёд. Всё посчитано на открытых данных ИС «Бюро госпитализации» с Ashyq Data и воспроизводится скриптом из репозитория.

Отдельно, как альтернативный взгляд на ту же задачу, Demeu работает со входом очереди: помогает врачу поликлиники собрать пакет обследований по приложению 5 Стандарта до отправки направления, а пациенту — пройти опрос до приёма.

## 1. Ядро по ТЗ: аналитика и прогноз нагрузки

**Данные.** Ashyq Data (data.gov.kz), набор `mz_bg_planned_hospitalization_referrals`: 767 130 направлений на плановую госпитализацию, зарегистрированных в I квартале 2025 года, исходы наблюдаются до 13.05.2026. Это данные кейса, на которые указал NITEC на консультации 18.09. Расширенную выгрузку (два года, регистры) команда запросила, ответа пока нет.

**Что видно.** Очередь в собственном смысле — направление из другой организации на круглосуточную койку. Остальное (59 % направлений) стационар выписывает сам себе, чаще в дневной стационар, и почти всегда без ожидания.

| По стране, очередь на круглосуточную койку | Значение |
|---|---|
| Направлений | 253 621 |
| Отказов | 20,2 % |
| Ожидание, медиана / 90-й процентиль | 7 / 70 дней |
| Ждали больше 30 дней | 20,9 % |

- **Регионы.** 20 регионов по коду КАТО. Больше всего отказов в очереди — Карагандинская (35,6 %) и Костанайская (34,6 %) области; дольше всего ждут в Алматинской области, г. Алматы и СКО (90-й процентиль 104–112 дней).
- **Стационары и сигнал перегрузки.** 642 организации с 300+ направлениями за квартал. Коечного фонда в открытых данных нет, поэтому перегрузка — косвенный сигнал: отказов или ожиданий больше 30 дней заметно больше, чем у стационаров с тем же набором профилей и целей (95 % интервал отношения «факт / ожидание» выше 1,5). Сигнал по отказам — у 71 организации, по ожиданию — у 51, по обоим — у 11.
- **Факторы отказа.** Направление из другой организации — 19,3 % отказов против 5,2 %, когда стационар направляет сам себе; лечение в другом регионе — в 1,6 раза выше среднего; оперативное лечение — в 1,45 раза; «платно для незастрахованных» — 73,5 %.

**Прогноз поступлений на месяц вперёд.** Для каждого из 642 стационаров: на данных, известных на 01.03.2025, прогноз поступлений за март. Модель потока (ожидающие направления × доля поступивших + новые направления по темпу на рабочий день) усредняется с февралём, пересчитанным по рабочим дням.

| Вариант | Ошибка WAPE |
|---|---|
| «Как в феврале», на 31 календарный день | 27,8 % |
| «Как в феврале», по рабочим дням | 12,8 % |
| Итоговый прогноз | 12,1 % |

Главный вклад даёт производственный календарь: в марте 2025 года 17 рабочих дней против 20 в феврале. Модель лучше базового прогноза ненамного; итоговый вариант выбран из трёх после сравнения на марте, все варианты и метрики лежат в JSON. По стране: прогноз 175 865 поступлений, факт 176 416.

**Модели по направлению.**
- Риск отказа (B3, логистическая регрессия): на отложенном марте ROC-AUC 0,779, PR-AUC 0,348 против 0,313 у частоты отказов пары «стационар × профиль» и 0,110 у константы. Признаки — только то, что известно при регистрации. Метрики и статус модели отдаются через `GET /api/models`; в карточку направления модель пока не встроена.
- Срок ожидания (D1): ошибка 3,58 дня против 3,62 у медианы по стационару и профилю. Выигрыша практически нет, поэтому для ожидания честнее опираться на медиану и разброс по стационару и профилю — они есть в аналитике раздела выше.

**Как воспроизвести.**

```bash
bash scripts/case1_analytics/download.sh data/raw/case1
python -m scripts.case1_analytics.build_aggregates --raw data/raw/case1
# -> data/case1/aggregates.json за ~15 секунд, только агрегаты, без строк пациентов
```

Методика, определения и ограничения — `docs/case1-analytics.md`. Модели B3 и D1 — `docs/referral-ml.md`, `docs/referral-refusal-benchmark.md`.

## 2. Альтернатива: вход очереди

Жалоба врачей в кастдеве — направление возвращается из приёмного покоя, потому что пакет обследований неполный или просрочен. В открытых данных причины отказа нет, поэтому это гипотеза, которую проверяем в пилоте, а не установленный факт.

- **Пакет обследований по приложению 5.** Справочник по приложению 5 к Стандарту стационарной помощи (приказ МЗ РК № ҚР-ДСМ-27, редакция приказа от 17.02.2025 № 9; на приложение ссылается пункт 33): 8 профилей, 148 требований, 57 исследований, сроки годности. Врач видит комплектность направления до отправки, пациент получает памятку. Справочник помечен `validated: false`: до проверки врачом больницы комплектность показывается как «неизвестно», итоговое решение за врачом.
- **Опрос пациента до приёма.** Пациент по ссылке отвечает на вопросы на русском или казахском, правила безопасности проверяют каждый ответ на красные флаги до вызова модели, врач получает сводку в кабинет и в Telegram. Диагноз пациенту не ставится.
- **API.** Направления, справочник, агрегаты и метрики моделей доступны по API с порталом документации `/api-docs`. Интеграции с МИС нет; API показывает готовность к подключению.

## Ограничения

- Один квартал данных: сезонности и годового тренда не видно.
- Строки — направления, не уникальные пациенты.
- Причина отказа не публикуется; коечного фонда нет, перегрузка — косвенный сигнал.
- Пролеченные случаи (ЭРСБ) и лабораторная нагрузка (ЕИП) в аналитику не входят: для лабораторий нет событий исследований в открытых данных.
- Красные флаги проверены на 160 синтетических фразах, на которых правила и дорабатывались; клиническая проверка впереди.
- Опрос и кабинет работают только с вымышленными пациентами.
