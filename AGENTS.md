## 1. Что за проект

Demeu — AI-ассистент первичного триажа и сбора анамнеза для госполиклиник РК (хакатон GovTech Camp, дедлайн **17.07.2026, 23:59 GMT+5**).
Врач жмёт «Сгенерировать ссылку» → получает персональную ссылку → пациент открывает её и проходит диалог с агентом-опросником (сбор жалобы, характеристик симптома, анамнеза, контекста).

Когда диалог завершён (маркер завершения, исчерпание turn cap или кнопка «Завершить»), запускается аналитический слой: LLM извлекает сущности (`Anamnesis`) и вектор признаков в пространстве DDXPlus (`EvidenceVector`); rule-based детектор ищет красные флаги с дословной цитатой пациента; обученная модель (multinomial logistic regression, веса в JSON) даёт распределение по патологиям; таблица маршрутизации суммирует вероятности по специальностям и даёт срочность; правила побеждают модель; формируется предварительная гипотеза с обязательным disclaimer. Сводка (текст + PDF) уходит врачу в **Telegram** через собственного бота.

Слово «диагноз» **не употребляется нигде** — ни в коде, ни в идентификаторах, ни в комментариях, ни в промптах, ни в UI, ни в README, ни в коммит-месседжах — **кроме отрицательных конструкций** («это не диагноз», «мы не ставим диагноз»).

### 6.2. Четыре золотых инварианта
Они обязаны пережить подмену LLM на обученную модель. Тесты пишутся **на моках через порты** (`analyze(messages, deps?: { llm?: LlmPort; model?: ModelPort })` — порты часть контракта, `vi.mock` не нужен), в GATE 3 гоняются **без изменений**:

1. **Emergency-флаг доминирует.** `red_flags.some(f => f.emergency)` ⇒ `urgency === "emergency"` — **независимо от выхода модели**. Правила побеждают модель, всегда.
2. **Evidence проверяема.** При `evidence_kind === "quote"`: `red_flag.evidence` — подстрока `messages[source_message_index].content`, и `messages[source_message_index].role === "user"`; цитата не обрывается посреди слова. При `evidence_kind === "derived"`: `source_message_index === -1`, инвариант не применяется.
3. **`TriageResult` контрактно полон.** Все поля SPINE §2 присутствуют, `source` заполнен; объект `model` присутствует **⟺** модель реально считалась (при abstain остаётся ради аудита с обнулёнными `pathologies`/`top_contributions`; при `rules_only` отсутствует).
4. **`hypothesis.disclaimer` непустой** и содержит оговорку «это не диагноз, решает врач».

> Инвариант evidence проверяет **проверяемость** цитаты, а не её **истинность**: фраза «боли в груди нет» даёт валидную подстроку при ложном флаге. Ложные срабатывания на отрицаниях ловит **отдельный негативный набор фикстур**. «Инварианты зелёные» ≠ «флаги корректны».

### 6.3. Дополнительно, по типу задачи
- Красные флаги: фикстура **на каждый regex-паттерн** (не по одной на правило), `m[0]` сверяется через `toBe`.
- Модель: **красный parity-тест Python↔TS ЗАПРЕЩАЕТ интеграцию модели.** Это стоп-кран, а не «известная неточность»: `source` остаётся `llm_fallback`, модель в прод не идёт, в README пишется честно.
- Валидатор `sum(pathologies.prob) === 1` писать **нельзя**: `pathologies` — top-5, сумма по нему < 1. Сумма = 1 только по полному `class_order`.
